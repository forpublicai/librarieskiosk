# Logos

The Public AI Libraries Project marks, copied from the kiosk's `public/images/`.

- `lib-logo.png`: the full lockup (square mark, "Public AI", "Libraries Project") in Public AI red (`red`, `#ef3c24`) on a transparent ground. Use it on every screen, in Light and in Dark. It reads on Dark grounds at 4.7:1.
- `logo.svg`: the compact lockup. The square is `red` and the "Public AI" letters are WHITE (`#ffffff`). Do not use it in the kiosk. It stays here for reference only.

Do not recolor, stretch, outline or add shadows to either mark. Keep clear space around the mark equal to half the height of the red square.
