# Highlight

A sunflower marker behind one key word, to give a heading a playful, human touch.

## Props
- `children`: the word to mark. The text turns `on-sun` (ink) on a `sun` fill, 11:1 in both themes.

## Do and do not
- Use it once per screen at most, on an empty state. The Home greeting does not use it.
- Mark one short word, not a phrase.
- Do not use it on links, buttons or body text.
- Do not use a red wavy underline instead. It reads as a spelling error.
